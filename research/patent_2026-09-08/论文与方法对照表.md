# 无人机语言引导搜索、目标确认与跟踪：论文近邻核查

检索截止：2026-09-08。以下只采用论文原文、作者项目页、作者代码库、会议官方网站作为技术依据。日期优先记首次 arXiv 提交日期；会议时间与代码公开时间另记。是否构成某件申请的现有技术取决于实际申请日/优先权日，不能把所有 2026 年资料自动用于评价更早申请。代码库现状未实跑；“有源码”不等于已验证一键可复现。

## 最接近、应优先阅读的八组工作

### P01 AirHunt

- **准确标题**：AirHunt: Bridging VLM Semantics and Continuous Planning for Efficient Aerial Object Navigation。
- **日期**：2026-01-19 首次 arXiv 提交。
- **来源**：[论文记录](https://arxiv.org/abs/2601.12742)、[原文 III-B / IV-A / IV-B](https://arxiv.org/html/2601.12742v1)、[作者仓库](https://github.com/Robotics-STAR-Lab/AirHunt)。
- **已公开机制**：无人机在室外按自然语言搜索开放集合目标。低频 VLM 与高频连续规划异步运行；覆盖关键帧用于区域目标概率推断，任务关键帧用于检测候选的语义核实；几何投影构建 3D 价值图。候选核实利用外观、颜色及空间上下文。
- **与本地摘要的关系**：这是“连续飞行 + 低频异步 VLM + 检测候选复核”的首要近邻，不能把这些宽泛组合单独作为新颖性依据。原文重点在语义地图和搜索路径，所读章节未明确给出本地的任务/候选/帧/版本联合回包校验、首次确认必须当前量测、预测仅限跟踪等规则；该差别仍须精确检索，不能宣称论文必然没有。
- **基线可用性**：作者仓库当前只有 README/assets，写有“Code coming soon”。可作最接近技术对照；实验需按论文重实现并标注，不能称直接跑原作者代码。

### P02 RTNav

- **准确标题**：RTNav: Towards Real-Time Zero-Shot Object Navigation。
- **日期**：2026-08-27 首次 arXiv 提交，是很新的公开资料。
- **来源**：[论文记录](https://arxiv.org/abs/2608.26496)、[原文 III / IV](https://arxiv.org/html/2608.26496v1)、[代码及基线环境](https://github.com/generalroboticslab/RTNav)。
- **已公开机制**：感知、建图、规划、导航独立线程；高频 OWLv2 提名候选，按需 Qwen3.5-9B 作语义验证，确认框经 MobileSAM 和 RGB-D 投影入地图；推理时环境按墙钟继续演化。仓库提供同步/异步的同接口对照。
- **与本地摘要的关系**：已覆盖“快检测、慢语义复核、几何独立投影、异步模块”；本地是无人机执行和目标锁定生命周期，RTNav 是地面 ObjectNav，不能直接拿其论文成功率与本地无人机场景数值比较。
- **基线可用性**：有代码、Docker、ROS2/Habitat 评测和多个基线适配。适合移植“异步验证架构”并统一控制器、传感器、GPU 后比较，也适合借鉴其真实延迟评测方式；直接任务基线需改造。

### P03 NEUSIS

- **准确标题**：NEUSIS: A Compositional Neuro-Symbolic Framework for Autonomous Perception, Reasoning, and Planning in Complex UAV Search Missions。
- **日期**：2024-09-16 首次 arXiv；RA-L 2025，10(9):9502–9509，DOI 10.1109/LRA.2025.3592098。
- **来源**：[论文记录](https://arxiv.org/abs/2409.10196)、[原文 III-A / III-B / III-C](https://arxiv.org/html/2409.10196v1)、[官方仓库/期刊信息](https://github.com/ControlNet/NEUSIS)。
- **已公开机制**：语言描述兴趣目标与搜索区域，神经符号感知、属性分类及跟踪，概率世界模型，区域选择—导航—覆盖的分层规划。世界模型按物理约束过滤不合理深度/检测；跨帧融合同目标位置和属性，使用贝叶斯滤波及属性分布更新；匹配置信度达阈值才报告目标。
- **与本地摘要的关系**：它直接削弱“多帧属性确认 + 概率定位 + 置信阈值报告 + 分层无人机搜索”作为宽泛创新的依据。论文世界模型初始使用真实占据栅格/BEV 信息，且重点是有时限多目标搜索报告；本地当前量测与预测区分、候选生命周期与异步证据作废机制需另作窄特征比较。
- **基线可用性**：官方仓库当前只有 assets、README、LICENSE、CITATION，未见算法源码。适合作最接近技术/模块重实现对照；不要误写已开放完整代码。

### P04 OpenUAV / UAV-Need-Help / LLaMA-UAV

- **准确标题**：Towards Realistic UAV Vision-Language Navigation: Platform, Benchmark, and Methodology。
- **日期**：2024-10-09 首次 arXiv；作者仓库记载 2025-01-25 释放代码、数据、场景与模型。
- **来源**：[论文](https://arxiv.org/abs/2410.07087)、[项目页](https://prince687028.github.io/OpenUAV/)、[TravelUAV 官方源码](https://github.com/prince687028/TravelUAV)。
- **已公开机制**：真实动力学约束的无人机仿真、约 12k 目标导向轨迹；UAV-Need-Help 用目标描述、环境信息及不同程度助手提示完成物体搜索；导航模型接受多视图、任务、助手信息，分层生成轨迹。
- **与本地摘要的关系**：高度相似于“前往描述地点并找目标”的整体任务；它重点是语言到连续导航和助手交互，本地摘要强调候选精确确认、锁定、丢失重捕获，任务终点应重新定义后才可公平比较。
- **基线可用性**：有模型目录、src、评测脚本、GroundingDINO 权重指引及场景下载，是整机导航/搜索最实用的公开参考之一。仍需统一目标是否可移动、位置先验、助手信息、飞行动力学与终止标准。

### P05 UNIFollow

- **准确标题**：UNIFollow: Natural Language Conditioned Target Following Framework for UAVs。
- **作者**：V. R. Vasudevan、Suhani Grover、Indu Sreedevi。
- **日期**：2025 年 IROS LeaPRiDE workshop 公开稿；检索定位到会议投稿 PDF，页面正文访问触发验证，精确首次公开日需进一步核对，不能仅依搜索引擎“11个月前”作法律证据。
- **来源**：[OpenReview 论文 PDF](https://openreview.net/pdf?id=oMlhfrv52K)、[同稿 PDF 链接](https://openreview.net/pdf/9e42fe78b28b43f42920b31e53a2fe284e5c1942.pdf)。技术内容来自可检索的该原始 PDF 索引。
- **已公开机制**：自然语言指定任意目标；OWL-ViT 零样本检测、CSRT 跟踪、跟踪失败后重新检测；远距离云台定位与近距离视觉伺服/自适应控制，在 AirSim 山地场景实验。
- **与本地摘要的关系**：是“语言指定对象→锁定跟随→失败重检测”的直接场景近邻；不等同于“先飞到指定区域再搜索”，也尚未核实其有本地多帧 RGB-D 属性证据、量测有效期与候选版本约束。
- **基线可用性**：本轮未找到经作者确认的源码。可按检测—跟踪—重检测模块复现，明确“论文方法重实现”。

### P06 UAV-VLRR

- **准确标题**：UAV-VLRR: Vision-Language Informed NMPC for Rapid Response in UAV Search and Rescue。
- **日期**：2025-03-04 首次 arXiv。
- **来源**：[论文](https://arxiv.org/abs/2503.02465)。
- **已公开机制**：VLM/ChatGPT-4o 解释场景和操作者意图，NMPC 将语义系统输出转为快速避障飞行；以应急搜索救援为示例，并报告与商用自动驾驶及人工飞手的响应时间对比。
- **与本地摘要的关系**：直接覆盖“语义理解—指定目标—底层控制器执行”的分层思路；重点在快速响应与轨迹控制，不能据其摘要推断支持本地候选身份管理、异步复核防过期、多机去重。
- **基线可用性**：本轮未核实官方可运行代码。适合控制/响应阶段的技术对照，若采用应公开重实现细节并维持相同控制资源。

### P07 SAP-Nav

- **准确标题**：SAP-Nav: Spatial Semantic Representation Meets Active Perception for Hierarchical Open-Vocabulary Object Navigation。
- **日期**：2026-08-13 首次 arXiv。
- **来源**：[论文记录](https://arxiv.org/abs/2608.12707)、[原文 Active Viewpoint Verification](https://arxiv.org/html/2608.12707v1)。
- **已公开机制**：先以在线空间语义表示约束房间/区域，再评估候选视图的可见性和观察角度是否足够；不足则选可达且可见的视点重观测；VLM 按类别和颜色等属性核实，错误候选进入黑名单后继续搜索。
- **与本地摘要的关系**：可直接对照 INSPECT 的“因证据不足改变视点并再次确认”。论文为地面室内导航，没有因此证明其覆盖空中 3D 视点、同步深度量测质量或移动目标证据老化。
- **基线可用性**：论文写明录用后公开代码，目前不宜标记现成可复现。适合主动确认模块的原理基线或自行复现。

### P08 STRIVE

- **准确标题**：STRIVE: Structured Representation Integrating VLM Reasoning for Efficient Object Navigation。
- **日期**：2025-05-10 首次 arXiv；项目页标 ICRA 2026。
- **来源**：[论文记录](https://arxiv.org/abs/2505.06729)、[作者论文 PDF，VLM-Based Target Verification](https://haokunzhu.com/STRIVE.github.io/static/pdf/ICRA%20%285%29.pdf)、[项目页](https://haokunzhu.com/STRIVE.github.io/)、[代码库](https://github.com/igzat1no/STRIVE)。
- **已公开机制**：在线构建房间/对象/视点三层表示，选择性调用 VLM；候选检测后使用周边上下文核实；首次视点不佳时，在接近目标路径上选择优化视点做二次 VLM 核实，兼顾误报和行程。
- **与本地摘要的关系**：说明“只在必要时调用 VLM + 检测后的语义二次确认 + 改善视点”已有公开；室内类别 ObjectNav 与无人机移动目标跟随仍需模块化适配。
- **基线可用性**：有作者关联的源码及 Habitat 运行入口，适合移植核实模块。同名 arXiv 不同版本实验数量和提升幅度有变化，比较时应固定版本，不拼接数值。

## 对主报告的判断建议（分析推断，不是已有文献结论）

1. 宽泛构思已很拥挤。不能据“自己把 YOLO、VLM、RGB-D、Kalman、无人机技能接起来”推断可授权；至少 AirHunt/RTNav 已接近语义与几何/控制解耦，NEUSIS 已接近多帧属性与概率定位融合，UNIFollow 已接近语言跟随和丢失后重检测。
2. 若本地实现足够具体，建议围绕**候选身份和时效一致的多模态证据门控**检索/提炼：每条语义结论绑定物理候选身份、任务版本与证据帧；返回时核验时效和当前可见量测；不把纯预测视为首次确认或新目标证据；失效结论触发何种补充观测或重捕获。把条件、输入、变换及状态转移明确写出，说明它如何减少过期回包导致误锁，不能仅写“保证安全”。
3. **多帧 RGB-D 前景属性与几何估计耦合**可作为另一条窄检索线，但 NEUSIS 和 EMAP 已公开许多组件。需明确前景掩膜如何决定可用像素、跨帧关联、残差权重/协方差、语义复核触发条件，以及与普通时域平均或 Kalman 的不同。
4. 对 **主动视点选择** 不宜泛化声称创新：SAP-Nav、STRIVE、STEM 已覆盖相关技术。若拟拓展，要求视点由“待消除的属性歧义/深度不可观测方向/当前追踪不确定性”具体驱动，再证明飞行成本与误确认收益；这属于待设计验证方案，不得写成本地已实现。

## 建议最小实验对照组合

这是为本地系统提出的实验设计，不是文献已报告结果：

- **整机任务**：OpenUAV/LLaMA-UAV，外加传统 GOTO→固定覆盖搜索→YOLO/BoT-SORT→阈值锁定。固定地点先验、目标类型、相机、动力学、碰撞条件和超时。
- **候选确认**：单帧检测阈值；多帧 RGB-D 确认；检测+单帧 VLM；STRIVE式换视点二次验证；完整候选证据方案。维持相同检测器和 VLM，避免把换模型带来的增益归因于方法。
- **时延一致性**：同步复核；朴素异步复核；RTNav式模块异步；增加任务/候选/帧/版本/时间校验。主动注入 0.2/1/3/5 秒延迟、回包乱序、任务切换和候选 ID 切换，记录错误接受过期结论次数。
- **定位跟踪**：原 BoT-SORT；深度投影+普通 Kalman；EMAP式自运动补偿；本地带测量有效性/协方差的方法；丢失后重检测参考 UNIFollow。统一控制器，并记录首次误锁率、ID切换、3D定位误差、遮挡后的重捕获时间。
- **任务指标**：正确目标确认率、误锁率、确认延迟、持续正确锁定比例、重捕获成功率、超时/碰撞、VLM 调用量和总墙钟时间。成功应同时要求目标身份正确、证据满足量测条件、维持规定时长；不能仅采用到目标距离阈值。
